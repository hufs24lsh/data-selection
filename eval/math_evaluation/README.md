# Math Evaluation

This evaluator is adapted from [math-evaluation-harness](https://github.com/ZubinGou/math-evaluation-harness), with its [MIT license](LICENSE) retained.

For ShallowFrontier, install the dependencies listed in [requirements/requirements_eval.txt](../../requirements/requirements_eval.txt) from the repository root and follow the official evaluation commands in the [root README](../../README.md). The upstream evaluator's model-specific examples are not the ShallowFrontier evaluation procedure.
